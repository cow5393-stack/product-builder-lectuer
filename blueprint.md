
# Lotto Number Drawing Site

## Overview

This project is a web-based Lotto number drawing application. It provides users with a fun and interactive way to generate random lottery numbers. The application is built using modern web technologies, including HTML, CSS, and JavaScript, and features a visually appealing and responsive design.

## Style, Design, and Features

### Visual Design
*   **Aesthetics:** The application has a clean, modern, and engaging user interface.
*   **Color Palette:** A vibrant color palette is used to create an energetic look and feel. The background has a subtle noise texture for a premium, tactile feel.
*   **Typography:** Expressive and clear typography is used to enhance readability and user experience.
*   **Layout:** The layout is visually balanced, with clean spacing and a responsive design that adapts to different screen sizes.
*   **Visual Effects:** Multi-layered drop shadows are used to create a sense of depth. The lotto balls have a soft, deep shadow to look "lifted."
*   **Interactivity:** The "Generate Numbers" button has a shadow with an elegant use of color to create a "glow" effect on hover.

### Features
*   **Lotto Number Generation:** Users can click a button to generate a set of 6 unique random numbers between 1 and 45.
*   **Number Display:** The generated numbers are displayed in a visually appealing way, with each number appearing inside a colored ball.
*   **Web Components:** The application uses a custom `<lotto-ball>` element to encapsulate the structure, style, and behavior of each lottery number ball.
*   **Responsive Design:** The application is fully responsive and works seamlessly on both desktop and mobile devices.
